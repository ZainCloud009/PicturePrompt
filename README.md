## 🌐 4. Domain (pictureprompt.world) Par Website Ko Live Kaise Karen?

Aapki website pure HTML, CSS aur JavaScript par bani hai. Is ka matlab yeh **100% fast, responsive aur secure** hai. Isy live karne ke 2 sab se aasan tareeqay:

### **Tareeqa A: Cloudflare Pages / Vercel / Netlify (Recommended & 100% Free)**
1. **GitHub** par aik free repository banayein aur is folder `f:\AI picture Website` ki tamam files wahan upload/push kar dein.
2. [Vercel.com](https://vercel.com) ya [Cloudflare Pages](https://pages.cloudflare.com) par login karen.
3. Apna GitHub repo select karke **Deploy** par click karen (10 seconds me website live ho jayegi).
4. Vercel / Cloudflare me **Custom Domain** setting me jayein aur `pictureprompt.world` add karen.
5. Domain registrar (jahan se domain buy ki hai, e.g. Namecheap, GoDaddy, Hostinger) me ja kar Vercel/Cloudflare ke DNS records (A Record / CNAME) paste kar dein.
6. **Free SSL Certificate (HTTPS)** automatically activate ho jayega!

### **Tareeqa B: Standard cPanel / Shared Hosting (Hostinger, Namecheap, etc.)**
1. Apne hosting cPanel me **File Manager** open karen.
2. `public_html` folder me jayein.
3. Is folder `f:\AI picture Website` ki tamam files (`index.html`, `styles.css`, `app.js`, `sitemap.xml`, `robots.txt`) ko `public_html` me upload kar dein.
4. Website `https://pictureprompt.world/` par live ho jayegi!
